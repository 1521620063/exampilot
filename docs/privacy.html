隐私政策

最后更新：2026 年 7 月 15 日

概述

ExamPilot（以下简称"本扩展"）是一款基于视觉 AI 的智能解题工具。本隐私政策说明了本扩展处理用户数据的方式。使用本扩展即表示您同意本政策所述的数据处理方式。

本扩展收集和处理的数据

1. 网页截图

  • 收集方式：当您在扩展面板中点击"全屏"或"区域"按钮时，Chrome 会截取当前浏览器视口或您框选区域的截图。双击页面仅用于显示或隐藏扩展面板，不会触发截图。
  • 使用目的：截图被发送到您自行配置的 AI 大模型 API，用于识别图片中的题目并生成解答。
  • 传输方式：截图以 base64 编码直接嵌入 API 请求，不经过任何中间服务器。
  • 存储与保留：截图不会持久存储在您的设备或本扩展的开发者服务器上。AI API 处理完成后，截图仅存在于 API 提供方的系统中，其保留政策请参阅相应 API 提供方的隐私政策。

2. AI 配置信息

  • 收集方式：您在扩展设置页面（⚙️）中填写的配置信息，包括 API 地址、模型名称、API 密钥、自定义请求头/请求体、请求模板、响应模板和自定义提示词。
  • 存储位置：所有配置信息仅存储在浏览器的 chrome.storage.local 中，不会传输到开发者服务器。
  • 使用目的：仅用于向您指定的 AI API 发送请求；发起请求时，API 密钥及必要的自定义请求内容会直接发送给该 API 服务商。

3. 界面偏好设置

  • 收集方式：您在扩展设置页面中调整的界面透明度，以及拖动迷你面板后保存的相对位置等本地偏好。
  • 存储位置：仅存储在浏览器的 chrome.storage.local 中。
  • 使用目的：仅用于恢复扩展面板的本地显示效果，不会发送给 AI API 或开发者服务器。

4. 配置导入与导出

  • 导出内容：仅当您主动点击“导出配置”时，扩展才会在本地生成 JSON 备份。备份包含模型配置、API 密钥、自定义请求内容、自定义提示词和界面透明度，但不包含面板位置或 Chrome API 域名授权。
  • 文件处理：备份文件由浏览器直接下载到您选择的本地位置，不会上传到开发者服务器。该文件包含未加密的 API 密钥，应由您妥善保管。
  • 导入处理：仅当您主动选择文件并确认导入时，扩展才会在本地读取、校验并写入配置。导入文件不会上传到开发者服务器。

5. 不收集的数据

本扩展不收集以下数据：

  • 个人身份信息（姓名、邮箱、电话等）
  • 浏览历史、书签、密码
  • Cookie 或其他网站数据
  • 设备标识符或位置信息
  • 使用统计或分析数据
  • 用户行为跟踪数据

数据的共享与披露

本扩展的开发者不会收集、存储或分享您的任何个人数据。数据仅按以下方式与您指定的第三方服务交互：

  • AI API 服务商：截图内容、API 密钥及完成请求所需的自定义请求内容会直接发送到您自行配置并授权的 AI 服务 API。API 服务商对数据的处理受其自身隐私政策的约束。

本扩展不会将您的数据出售、出租或共享给任何其他第三方。

数据安全

本扩展采取以下安全措施：

  • API 密钥等敏感信息仅存储在浏览器的本地存储中
  • 配置备份仅在用户主动操作时于本地生成或读取，不经过开发者服务器
  • 所有 API 请求均使用 HTTPS 加密传输
  • API 域名采用可选权限按需授权，不在安装时申请所有网站访问权限
  • 不使用任何远程代码或分析 SDK
  • 极小权限设计：仅请求运行所必需的权限（storage、activeTab、scripting），API 域名按需单独授权

第三方链接

本扩展的配置页面允许您输入自定义的 API 地址，这些地址对应的服务由第三方独立运营，其隐私实践不在本政策的覆盖范围内。

政策更新

本隐私政策可能会不时更新。更新后的政策将在本页面公布，并更新页面顶部的"最后更新"日期。

Privacy Policy (English)

Last updated: July 15, 2026

Overview

ExamPilot is an AI-powered problem-solving tool that captures screenshots of web pages and sends them to user-configured AI vision API for analysis. This privacy policy explains how the extension handles user data.

Data Collected and Processed

1. Screenshots. When you click "全屏" or "区域" on the panel, Chrome captures a screenshot of the viewport or your selected region. Double-clicking the page only shows or hides the extension panel and does not trigger screenshot capture. Screenshots are sent to the AI API you have configured for problem recognition and solving. Screenshots are not stored persistently on your device or on the developer's servers. They exist only transiently during processing through the AI API you selected.

2. AI Configuration. API endpoint URLs, model names, API keys, custom headers/bodies, request templates, response templates, and custom prompts that you enter in the settings panel (⚙️) are stored exclusively in chrome.storage.local on your device. This information is used solely to make requests to the AI API of your choice and is never transmitted to the developer's servers.

3. UI Preferences. Local display preferences such as panel opacity and the relative position saved after dragging the mini panel are stored exclusively in chrome.storage.local. They are used only to restore the panel appearance and are not sent to AI APIs or developer servers.

4. Settings Import and Export. A JSON backup is created locally only when you click “Export Settings.” It contains model configurations, API keys, custom request data, custom prompts, and panel opacity, but not the panel position or Chrome API host permissions. The browser downloads the file directly and it is never uploaded to the developer's servers. API keys in the file are not encrypted. An import file is read, validated, and stored locally only after you select it and confirm the import.

5. No Data Collection. This extension does not collect personal information, browsing history, bookmarks, passwords, cookies, device identifiers, location data, usage analytics, or any tracking data.

Data Sharing

The developer does not collect, store, or share any personal data. The only data sharing is with third-party services you explicitly configure: the AI API provider you specify receives the screenshot, API key, and any custom request data required to process the request. No data is sold, rented, or shared with any other third party.
