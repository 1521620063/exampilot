隐私政策

最后更新：2026 年 5 月 16 日

概述

ExamPilot（以下简称"本扩展"）是一款基于视觉 AI 的智能解题工具。本隐私政策说明了本扩展处理用户数据的方式。使用本扩展即表示您同意本政策所述的数据处理方式。

本扩展收集和处理的数据

1. 网页截图

  • 收集方式：当您在网页上双击或点击"开始识别"按钮时，Chrome 会截取当前浏览器视口（viewport）的截图。
  • 使用目的：截图被发送到您自行配置的 AI 大模型 API，用于识别图片中的题目并生成解答。
  • 传输方式：截图可通过以下两种方式发送至 AI API：
    • Base64 直传（默认）：截图以 base64 编码直接嵌入 API 请求，不经过任何中间服务器。
    • OSS 中转：截图先上传到您自行配置的阿里云 OSS 存储桶，再将公开访问 URL 传递给 AI API。此模式需您自行提供 OSS 凭据。
  • 存储与保留：截图不会持久存储在您的设备或本扩展的开发者服务器上。AI API 处理完成后，截图仅存在于 API 提供方的系统中，其保留政策请参阅相应 API 提供方的隐私政策。

2. AI 配置信息

  • 收集方式：您在扩展设置页面（⚙️）中填写的配置信息，包括 API 地址、模型名称、API 密钥。
  • 存储位置：所有配置信息仅存储在浏览器的 chrome.storage.local 中，不会传输到任何第三方服务器。
  • 使用目的：仅用于向您指定的 AI API 发送请求。

3. 不收集的数据

本扩展不收集以下数据：

  • 个人身份信息（姓名、邮箱、电话等）
  • 浏览历史、书签、密码
  • Cookie 或其他网站数据
  • 设备标识符或位置信息
  • 使用统计或分析数据
  • 用户行为跟踪数据

数据的共享与披露

本扩展的开发者不会收集、存储或分享您的任何个人数据。数据仅按以下方式与您指定的第三方服务交互：

  • AI API 服务商：截图内容被发送到您自行配置并授权的 AI 服务 API。API 服务商对数据的处理受其自身隐私政策的约束。
  • 阿里云 OSS（仅在您启用 OSS 模式时）：截图临时存储于您自行配置的 OSS 存储桶中。数据受阿里云隐私政策的约束。

本扩展不会将您的数据出售、出租或共享给任何其他第三方。

数据安全

本扩展采取以下安全措施：

  • API 密钥等敏感信息仅存储在浏览器的本地存储中
  • 所有 API 请求均使用 HTTPS 加密传输
  • 不使用任何远程代码或分析 SDK
  • 极小权限设计：仅请求运行所必需的权限（offscreen、storage、activeTab）

第三方链接

本扩展的配置页面允许您输入自定义的 API 地址，这些地址对应的服务由第三方独立运营，其隐私实践不在本政策的覆盖范围内。

政策更新

本隐私政策可能会不时更新。更新后的政策将在本页面公布，并更新页面顶部的"最后更新"日期。

Privacy Policy (English)

Last updated: May 16, 2026

Overview

ExamPilot is an AI-powered problem-solving tool that captures screenshots of web pages and sends them to user-configured AI vision API for analysis. This privacy policy explains how the extension handles user data.

Data Collected and Processed

1. Screenshots. When you double-click or click "开始识别" on a webpage, Chrome captures a screenshot of the current viewport. This screenshot is sent to the AI API you have configured for problem recognition and solving. Screenshots are not stored persistently on your device or on the developer's servers. They exist only transiently during processing through the AI API you selected.

2. AI Configuration. API endpoint URLs, model names, and API keys that you enter in the settings panel (⚙️) are stored exclusively in chrome.storage.local on your device. This information is used solely to make requests to the AI API of your choice and is never transmitted to the developer's servers.

3. No Data Collection. This extension does not collect personal information, browsing history, bookmarks, passwords, cookies, device identifiers, location data, usage analytics, or any tracking data.

Data Sharing

The developer does not collect, store, or share any personal data. The only data sharing is with third-party services you explicitly configure: (a) the AI API provider you specify receives the screenshot content for processing, and (b) if OSS mode is enabled, screenshots temporarily pass through your own Aliyun OSS bucket. No data is sold, rented, or shared with any other third party.
